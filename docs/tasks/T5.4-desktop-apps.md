- **Agent / Tooling Versions**:

  - Anthropic Claude Desktop v0.7.0+.
  - Google Antigravity v1.0.0+ (Chrome DevTools Protocol port active).
  - SQLite 3.43+ (WAL journal mode).
- **Established Facts**:
  - Reading and live-syncing ChatGPT Desktop / Codex app sessions is 100% reliable via `~/.codex/sessions/` rollout logs without IPC dependencies.
  - Antigravity uses independent SQLite databases per conversation in WAL mode. `PRAGMA query_only = ON` allows concurrent reads without locking or corrupting active turns.
  - Claude Desktop maintains separate session state from the CLI; reading is limited to local cache, and writing directly into Electron UI via Accessibility is fragile and rejected.
  - Writing to sessions started in desktop apps is cleanly supported by resuming the session via the agent CLI (`codex resume <id>` or `claude resume <id>`) under Shardrail's managed PTY.
- **Unknowns / Hypotheses**:
  - File locking behavior during sudden desktop app termination: SQLite WAL handles unclean exits via standard WAL checkpoint recovery on next read; Codex JSONL files remain intact up to the last flushed turn.

## 3. Implementation Summary

- **Architecture & Invariants**:
  - Read-only safety: All SQLite connections opened with `SQLITE_OPEN_READONLY | SQLITE_OPEN_URI` and `PRAGMA query_only = ON`.
  - Non-destructive sync: Shardrail never mutates desktop application databases directly.
  - Append-only journal: External events are appended to Shardrail's durable journal with metadata identifying their desktop app origin.
