## 3. Implementation Details & Optimizations Applied
- **Delta Coalescing**:
  - Daemon batches token-level events into 16.6ms frame chunks before WebSocket serialization, preventing network saturation.
- **SQLite WAL Indexing**:
  - `PRAGMA synchronous = NORMAL`, `PRAGMA journal_mode = WAL`, and explicit index on `(session_id, cursor)` allow sub-millisecond seek times even on 50,000+ row journals.
- **Zero-Copy / Ring Buffer PTY Streaming**:
  - PTY output buffer maintains a fixed 64KB circular ring buffer in daemon memory per session. Memory usage is strictly bounded regardless of long-running terminal output.
