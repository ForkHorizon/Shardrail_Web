  - Ingress: Port 443 managed by Nginx `stream` module (`/etc/nginx/stream.d/vpn.conf`) with `ssl_preread on;` mapping SNI `shardrail.forkhorizon.com` to `127.0.0.1:8443`.
  - TLS Termination: Nginx HTTP server on `127.0.0.1:8443 ssl` with Let's Encrypt certificates (`/etc/letsencrypt/live/shardrail.forkhorizon.com/fullchain.pem`).

  - Relay Service: `shardrail-relay` listening on `127.0.0.1:4000`, running under unprivileged user `shardrail`.
- **Hub Threat Model (Archive D67 / D69 / D70)**:
  - **D67 Outbound Only**: Developer daemons (`shardraild`) dial outward to the public relay (`wss://shardrail.forkhorizon.com/ws`). The developer machine exposes zero listening ports to the Internet.
  - **D69 Untrusted Relay**: All application-level frames (turn inputs, approvals, terminal streams, file diffs) are end-to-end encrypted and signed with Ed25519/X25519 keys between browser client and daemon. The relay cannot inspect, tamper with, or forge messages.
  - **D70 Blind Envelope Routing**: The relay acts as an oblivious pipe, routing frames purely by envelope headers (`machine_id`, `client_id`).
  - **Client Revocation**: When an authorized client is un-paired / revoked, the daemon informs the relay via `control:revoke_client`. The relay terminates the active connection with WebSocket CloseCode `4003` ("Client Revoked").
