## 1. Research & Context
- Interactive Claude Code processes open a Unix Domain Socket at `/tmp/cc-socks/claude-code-<pid>.sock`.
- To enqueue a user turn into an active session, a client connects to the UDS socket, transmits the HMAC peerToken from `~/.claude/sessions/<pid>.token.key` on line 1, and sends a JSON payload on line 2 (`{"type":"user","message":"..."}`).
- For inactive sessions, Shardrail launches `claude` subprocesses via `ClaudeProcessManager` in stream-json mode (`--input-format=stream-json --output-format=stream-json`).
- Session interruption signals active subprocesses or returns `Err(AdapterError::SessionNotFound)` when inactive.

## 2. Design & Acceptance Criteria
- **Scope & Changes**:
