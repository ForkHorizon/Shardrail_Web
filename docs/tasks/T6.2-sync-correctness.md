## 1. Research & Context
- **Stress Vectors**:
  1. Simultaneous Writers (CLI agent, web client, desktop app on one session).
  2. Rapid Message Bursts (>1,000 events/sec streaming).
  3. Very Long Sessions (>50,000 events).
  4. Reconnect Storms (multiple concurrent reconnects during streaming).

## 2. Concurrency Architecture & Primitives
- **Single-Writer Detection**:
  - Codex uses `flock` on session directories (`crates/session-core/src/codex/lock.rs`).
  - Claude uses PID descriptor files (`crates/session-core/src/claude/lock.rs`).
- **Journal Monotonicity**:
  - SQLite events table uses autoincrement `cursor: i64`. Clients query `WHERE cursor > ?`.
- **UI Store Coalescing**:
  - React store coalesces streaming token deltas per animation frame (`session-model.ts`).
