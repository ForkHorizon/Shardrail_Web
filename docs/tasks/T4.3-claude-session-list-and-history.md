## 1. Research & Context
- **Official Documentation**: Claude Code CLI and Agent SDK storage specification (`~/.claude/projects/<slug>/<id>.jsonl`).
- **Installed Tooling Versions**: Claude Code 2.1.309 (darwin-arm64, node-v20.18.0).
- **Established Facts**:
  - Project directory slugs encode absolute working paths by replacing `/` with `-` (e.g. `-Users-daliys-Daliys-Projects-Shardrail`).
  - Sessions contain JSONL records with types `user`, `assistant`, `subagent`, `compact_boundary`, and `system`.
  - Companion files include `<id>/custom-title.json` for user-defined session titles and `<id>/subagents/` for sidechain transcripts.
  - Subagents are stored as `agent-<id>.jsonl` with companion `agent-<id>.meta.json`.

## 2. Design & Acceptance Criteria
- **Scope & Changes**:

  - Implement `read_session_history` and `read_history_from_jsonl` in `crates/session-core/src/claude/history.rs` converting JSONL records into `NormalizedTurn` and `NormalizedItem` with forward/backward cursor pagination and token accounting.
- **Acceptance Criteria**:
  - [x] All sessions on host discovered across projects with accurate workdir, status, model, and timing.
  - [x] Full history normalization covers text messages, thinking blocks (`Reasoning`), tool calls, tool results, subagents (`SubagentInvocation`), and system compaction notices (`SystemNotice`).
  - [x] Resilient parsing: skips corrupted lines and trailing incomplete writes gracefully.
  - [x] Bidirectional cursor pagination by turn ID.
