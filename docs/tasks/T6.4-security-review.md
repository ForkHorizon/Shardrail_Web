## 1. Security Scope & Threat Model
- **Threat Boundary**:
  - Outbound E2E-encrypted tunnel from `shardraild` to Relay.
  - Browser clients connecting to Relay and communicating with Daemon.
  - Local workstation filesystem and agent child processes (Codex, Claude, Antigravity).
- **Core Security Principles**:
  1. **Relay Compromise Assumption**: The relay server is untrusted. Relay must never have access to plaintext session content, agent outputs, commands, or approval secrets.
  2. **Fail-Closed Permissions**: Approvals and containment permissions default to deny.
  3. **Untrusted Agent Output**: Model text, tool responses, diffs, and terminal escapes are treated as untrusted inputs.
  4. **Zero Secrets in Storage/Logs**: Redaction filters strip API keys, bearer tokens, passwords, and private keys before journal persistence.
